Nothing here is a redesign. Same layout, same proportions, same button grid, same per-side colours from ControlBarScheme.ini, same hotkey letters, same queue clock, same radar. The only change is that the frame and its buttons are drawn at the size they are actually shown at, instead of an 800×600 picture stretched to the screen height. Positions are approximate. ControlBar.wnd is read from the installed game data, not from this repo, so the rects above follow the structure the code lays out (LeftHUD for the radar, RightHUD for the queue, MoneyDisplay, PowerWindow, GeneralsExp, the ButtonCommand01–14 grid sorted into 2 rows × 7 columns by [GenControlBar.cpp:114](Source/Generals1/Game/GenControlBar.cpp:114)) — not the original pixel coordinates. A real implementation would keep reading the real .wnd for positions, so the layout you see in game stays exactly as it is.

What drawing at native resolution actually fixes:

  • Button images. DrawMappedImage stretches textures made for 800×600 — at any other size they are resampled. Drawn as paths, edges stay hard at any resolution.
  • Text. DrawBarText uses a bitmap font sized for one size; other sizes fall back to the canvas font. One font rendered at the target size is readable at 1080p, 1440p and 4K.
  • The build-up clock. DrawRemainingClock sweeps from twelve o'clock; at the sizes it is drawn at today the sweep reads as chunky steps. Same sweep, antialiased.
  • The radar. It is redrawn every other logic frame at one texel per radar cell, so its resolution is fixed by the map, not the screen. Drawing at the panel's real size keeps blips and fog edges clean.
  • Colours. The scheme values are 0–255 sRGB handled as linear (the code converts them at [GenHUD.cpp:208](Source/Generals1/Game/GenHUD.cpp:208)); a redraw would use them as light, which is where the muddiness comes from.

What does not change: the layout, the sizes, the per-side scheme, the hotkey letters, the queue, the clock, the radar contents, health bars and selection rings, tooltips, the general's promotions. Nothing about how it behaves — only how it is drawn.
